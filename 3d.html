📖 回転記号（標準表記）の意味

ルービックキューブの回転記号は、見ている視点からの各面（英語の頭文字）を表します。

U (Up / 上面)

上面（白）を時計回りに回転

D (Down / 下面)

下面（黄）を時計回りに回転

R (Right / 右面)

右面（赤）を時計回りに回転

L (Left / 左面)

左面（橙）を時計回りに回転

F (Front / 前面)

前面（緑）を時計回りに回転

B (Back / 後面)

背面（青）を時計回りに回転

💡 アポストロフィ ( ' ) について

アルファベットの後ろに ' が付くもの（例: U', R'）は、その面を反時計回りに回す操作を表します。

時計回り (90°) U(上) / D(下) / R(右) / L(左) / F(前) / B(後)
反時計回り (-90°) U' / D' / R' / L' / F' / B'
